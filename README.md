# LRC 同步歌词助手 (GUI 版)

这个工具用于给文件夹里的音乐文件自动下载同名 `.lrc` 同步歌词文件，现已支持图形界面。

## 主要功能

- **图形界面 (GUI)**：提供直观的文件夹选择、选项配置和运行日志。
- **联网搜索下载**：双源搜索。首选 Meting 接口搜索网易云音乐，若无结果则自动尝试 `api.lrc.cx` 备用接口。只下载带时间轴的同步歌词。
- **本地歌词匹配**：将文件夹内已有的歌词文件按文件名相似度匹配并重命名。
- **运行日志**：实时展示程序运行过程中的每一个步骤。

## 使用说明

### 1. 运行工具
直接双击 `match_lrc.exe` 即可启动图形界面。

### 2. 图形界面操作
- **目标文件夹**：点击“浏览...”选择存放音乐的文件夹（默认为当前文件夹）。
- **选项配置**：
  - **递归子文件夹**：是否处理子目录下的音乐。
  - **覆盖已有歌词**：如果已存在同名 `.lrc` 文件，是否允许下载新歌词覆盖它。
  - **复制模式(本地)**：在进行本地匹配时，是重命名原文件还是复制一份。
- **执行操作**：
  - **联网搜索并下载**：开始搜索缺失的歌词并提供预览确认。
  - **本地重命名匹配**：根据文件名相似度整理本地歌词。

## 运行环境

- 系统：Windows
- 网络：需要能访问 `https://meting.mikus.ink`
- Go (开发/编译)：需要 Go 1.21 或更高版本

## 编译方法

如果你有 Go 环境，可以双击：
```text
build.cmd
```
或者在当前目录运行：
```powershell
go build -ldflags="-H windowsgui" -o match_lrc.exe .
```

## 命令行用法 (仍然支持)

如果需要自动化脚本调用，工具仍然保留了命令行支持：

```powershell
# 启动 GUI (无参数)
.\match_lrc.exe

# 命令行静默下载
.\match_lrc.exe --download --apply --nogui

# 指定文件夹并预览
.\match_lrc.exe D:\Music --download --nogui
```
