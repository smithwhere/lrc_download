# LRC 同步歌词助手 (GUI 版)

这个工具用于给文件夹里的音乐文件自动下载同名 `.lrc` 同步歌词文件和专辑封面图片，支持图形界面和命令行两种模式。

## 主要功能

- **图形界面 (GUI)**：提供直观的文件夹选择、选项配置和运行日志。
- **联网搜索下载歌词**：首选 QQ 音乐接口（`api.ygking.top`）搜索歌词，若无结果则自动尝试 `api.lrc.cx` 备用接口。只下载带时间轴的同步歌词。
- **联网搜索下载专辑图片**：通过 QQ 音乐接口搜索并下载每首歌曲的专辑封面图片，保存为同名 `.jpg` 文件。
- **本地歌词匹配**：将文件夹内已有的歌词文件按文件名相似度匹配并重命名。
- **多线程处理**：歌词搜索、封面搜索、文件下载均使用 5 线程并发执行，大幅提升批量处理速度。
- **智能文件名解析**：自动识别 "歌手 - 歌名" 和 "歌名 - 歌手" 两种命名格式，支持多位歌手（`范玮琪&张韶涵`、`张三/李四` 等）匹配。
- **运行日志**：实时展示程序运行过程中的每一个步骤。

## 使用说明

### 1. 运行工具
直接双击 `match_lrc.exe` 即可启动图形界面。

### 2. 图形界面操作
- **目标文件夹**：点击"浏览..."选择存放音乐的文件夹（默认为当前文件夹）。
- **选项配置**：
  - **递归子文件夹**：是否处理子目录下的音乐。
  - **覆盖已有文件**：勾选后允许覆盖已存在的 `.lrc` 歌词或 `.jpg` 封面文件。
- **执行操作**：
  - **联网搜索并下载歌词**：开始搜索缺失的歌词并提供预览确认。
  - **下载专辑图片**：搜索并下载每首歌曲的专辑封面图片。
  - **本地重命名匹配**：根据文件名相似度整理本地歌词。

### 3. 智能搜索策略

搜索歌词和封面时，程序自动执行多级匹配：

1. **标准搜索**：以歌名为关键词、歌手为过滤条件搜索。
2. **反向搜索**：交换歌名和歌手重新搜索（适配 "歌名 - 歌手" 文件名格式）。
3. **宽松搜索**：仅按歌名搜索，不限制歌手（适配文件名中歌手为专辑名或剧名的情况）。
4. **备用接口**：若 QQ 音乐无结果，自动尝试 `api.lrc.cx` 接口（歌词功能）。

## 运行环境

- 系统：Windows
- 网络：需要能访问 `https://api.ygking.top`（QQ音乐接口）
- Go (开发/编译)：需要 Go 1.25 或更高版本

## 编译方法

如果你有 Go 环境，可以双击：
```text
build.cmd
```
或者在当前目录运行：
```powershell
go build -ldflags="-H windowsgui" -o match_lrc.exe .
```

## 命令行用法 (仍然支持)

如果需要自动化脚本调用，工具仍然保留了命令行支持：

```powershell
# 启动 GUI (无参数)
.\match_lrc.exe

# 命令行静默下载歌词
.\match_lrc.exe --download --apply --nogui

# 命令行静默下载专辑图片
.\match_lrc.exe --cover --apply --nogui

# 同时下载歌词和专辑图片
.\match_lrc.exe --download --cover --apply --nogui

# 指定文件夹并预览
.\match_lrc.exe D:\Music --download --nogui

# 递归处理子文件夹
.\match_lrc.exe D:\Music --download --cover --apply --recursive --nogui
```

## 支持的音乐格式

`.mp3` `.flac` `.wav` `.m4a` `.aac` `.ogg` `.opus` `.wma` `.ape`
